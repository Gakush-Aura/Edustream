# UniStream — Smart University Management

**Your Campus. Your Progress. One Platform.**

UniStream is a responsive student workspace built with HTML, CSS and vanilla JavaScript. It brings everyday university planning tools together in one simple dashboard.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. No installation, server, build step or API key is required.

## Features
- Responsive dashboard with semester overview and study activity chart
- Assignment tracker: add, complete and delete assignments
- Weekly timetable sample
- Grade records and weighted-average calculator
- Quick notes saved automatically in browser LocalStorage
- Dark/light theme toggle

## Customise
- Change the greeting and initials in `index.html`.
- Edit the sample timetable and course progress to match your real schedule.
- The initial assignment data is sample data; replace it with your own.

## Deploy with GitHub Pages
1. Create a **public** GitHub repository named `UniStream`.
2. Upload `index.html`, `README.md` and `LICENSE` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
5. After deployment, your site will be available at `https://YOUR-USERNAME.github.io/UniStream/`.

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript · LocalStorage

## Important limitations
This is a front-end portfolio/demo project. Assignments, grades and notes are stored locally in the browser on the current device. They are not synced between browsers or devices. There is no real authentication system, backend or cloud database.
